# 鈍化

- 種別：呪いカード
- 実装状態：実装済み
- 使用：通常は使用不可。「お札」による例外は[共通仕様](./_SPEC.md)を参照。
- 発動条件：プレイヤーのターン終了時に手札にある。
- 効果：次のプレイヤーターンの手札リフレッシュ時に引く枚数を−1する。
- 通常5枚引く場合は4枚になる。手札に引かれた呪いもドロー枚数に含む。
- 暫定：他の補正と合算し、複数枚なら1枚につき−1を加算する。最終的なドロー枚数の下限は0とする。
- 手札リフレッシュにのみ適用する。そのターン中のカード効果などによる追加ドローには適用しない。
- 適用後に予約効果を解除する。その次のターンのドロー枚数には影響しない。
- カードの移動と戦闘終了時の扱いは共通仕様に従う。
