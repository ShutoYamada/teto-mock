# 封鎖

- 種別：呪いカード
- 実装状態：呪いカード・封鎖状態ともに実装済み
- 使用：通常は使用不可。「お札」による例外は[共通仕様](./_SPEC.md)を参照。
- 発動条件：プレイヤーのターン終了時に手札にある。
- 効果：次のプレイヤーターン中、ランダムに指定された1行または1列を封鎖状態にする。

## 対象の抽選・適用期間

- 封鎖状態自体の配置制限・解除は[戦闘仕様の盤面ステータス](../BATTLE/_SPEC.md#特殊状態盤面)を参照。
- 暫定：発動時に行・列を各50%で選び、その方向の全ラインから1本を等確率で抽選する。空のライン・既存ブロックのあるラインも候補に含め、次ターンの対象として予告する。
- 暫定：複数枚なら各カードが独立して抽選する。同じラインが重複した場合、封鎖範囲・期間は増えない。
- 次プレイヤーターン開始時に有効になり、そのターンの終了時に解除する。再発動による次ターンの予約とは別に管理する。
- カードの移動と戦闘終了時の扱いは[共通仕様](./_SPEC.md)に従う。
