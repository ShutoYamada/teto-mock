# 呪いカード：共通仕様

## 位置づけ・実装状態

- 基本ミノ・カスタムミノとは別のカード種別「呪い」を追加する。
- 呪いカード5種類、弱点ブロック、封鎖状態は実装済み。アーティファクト「お札」も実装済み。
- イベントなどの不利益としてデッキに混入し、山札から引かれると手札の枠を占める。具体的な入手イベント・追加枚数は各入手元で定義する。
- 通常の初期デッキ・戦闘カード報酬の抽選対象には含めない。

## 使用・カードの移動

- 通常は手札から使用できない。ミノの形状・配置時攻撃力を持たず、盤面への配置・回転は行わない。
- [お札](../ARTIFACT/Ofuda.md)を所持している場合、プレイヤーターン中に手札の呪いをクリックすると1MPを消費して捨て札へ送る。呪いの効果は発動せず、そのターン終了時の不利益を回避できる。消費MP・使用後の行き先は暫定。
- ドロー・リシャッフル・ターン終了時の捨て札化・戦闘終了時の山札への回収は、通常のカードと同じルールに従う。
- 効果の発動だけではデッキから削除・除外されない。再び引くと再発動する。

## 発動タイミング

- 今回の5種類は、プレイヤーのターン終了時、手札を捨て札へ送る直前に、手札にある各カードにつき1回発動する。
- 減衰・虚弱はその場で盤面へ配置する。枯渇・鈍化・封鎖は直後の次プレイヤーターンに適用する効果を予約する。
- ターン終了時より前に手札から離れた呪いは発動しない。
- 戦闘終了による手札回収では発動しない。予約効果と封鎖状態は戦闘終了時に解除し、次の戦闘へ持ち越さない。

## 暫定ルール（指定のない細部）

以下は仕様化のための暫定ルール。バランス調整時に見直す。

- 複数の呪いは手札の並び順に処理する。同名カードもそれぞれ発動する。
- ランダムなブロック配置は、盤面内の空きマスから重複なし・等確率で選ぶ。既存ブロックを上書きせず、空きマスが3未満なら置ける数だけ置く。配置可能な空きマスがなければ何も配置しない。
- 呪いによる直接配置はミノカードの使用と扱わず、MP消費・配置時攻撃・配置時効果を発生させない。これ自体によるライン消去は行わず、以後の通常のライン消去や破壊の対象とする。
- 次ターンへの効果は1回分のみ。同名の枯渇・鈍化は減少量を加算する。封鎖の重複は個別仕様に従う。

## 実装との接続

- `src/curses.ts`の`createCurseCard`で呪いを生成し、`addCurseToDeck`でデッキに追加する。各入手イベントの具体的な内容は未定のため、既存イベントへの混入はまだ行わない。
- 呪いカードは手札・山札などで日本語名、「呪い・使用不可」、発動効果を表示する。手札から選択・回転・配置はできない。「お札」所持時はコスト「1」と「呪い・お札で使用」を表示し、クリックで使用する。
- 弱点ブロックは盤面に「💔」、現在の被ダメージ加算量は戦闘HUDに表示する。
- 有効な封鎖マスには「封」と枠を表示し、配置プレビュー・実際の配置の両方で禁止する。対象ラインと残り期間を表示し、敵ターン中は予約された次ターンのMP減少・ドロー減少・封鎖対象を表示する。
