# 変化の霧

- 出現ステージ数：1
- 「変化の霧が立ち込める」と表示し「飛び込む」と「何かを投げ込む」と「無視する」の選択肢を提示
- 「飛び込む」：所持Goldを全額失う（残金0G）。Goldが1以上かつ基礎カードが1枚以上ある場合のみ選択可能。デッキの中の基礎カード(I,O,T,S,Z,J,L)をすべて、対応したエンハンスドカードに入れ替える
- 「何かを投げ込む」：デッキの中のカードを1枚選択する。そのカードをランダムなカードと入れ替える
- 「無視する」：「霧は晴れ、何も変わらなかった」と表示し、何も起こらない

- 「何かを投げ込む」「無視する」ではGoldを失わない
- 飛び込む選択肢には現在の所持Gold全額と全基礎ミノが強化される旨を表示し、0G・対象なしの場合は選択不可の理由を示す
- Enhancedへの置換は過去の攻撃力低下を引き継がず、既存のEnhanced定義の攻撃力・コスト・形状・特殊ブロック・色・レアリティを適用する
