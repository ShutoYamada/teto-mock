# 怪しげな魔術

- イベントID：`suspicious_magic`
- 出現ステージ：1・2・3
- 「暗がりの魔術師が囁く。ミノをひとつ選びなさい。力を授けよう」と提示する
- 対象はデッキ内に存在する基礎ミノ（I・O・T・S・Z・J・L）。種類ごとに選択し、同じ種類の全カードを対応するEnhancedへ置換する。1枚だけの選択ではない
- 各候補に対象枚数と変換先を示す。選択後は対象枚数、変換先、強化後の攻撃力・コスト、Goldを消費しない旨を表示する
- 「無料で強化する」で確定するまではデッキを変更しない。別の種類への選び直しが可能
- 対象の基礎ミノが1枚以上ある場合のみ実行可能。対象なしの場合は理由を表示する。Gold消費はなく、0Gでも利用可能
- 変換後の形状、特殊ブロック、色、攻撃力、コスト、効果テキスト、レアリティは既存のEnhanced定義に従う。カードIDとデッキ枚数・順序は維持する
- 他の種類・既存Enhanced・カスタムミノは変化しない。今後入手する同種カードを自動強化する効果はない
- 「立ち去る」は無償。強化または立ち去るとイベントを終了しマップへ戻る
