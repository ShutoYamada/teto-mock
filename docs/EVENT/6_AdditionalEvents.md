# 追加6イベント

## 共通

- 各イベントは出現ステージを満たすと、ショップ抽選に外れたイベントマスで既存イベントと等確率で出現する
- 全イベントに無償の「立ち去る」を設け、選択前に効果、代償、確率、利用条件を明示する
- 対象選択中の選び直しは自由。確定後に効果を1回だけ適用し、実際の変化を結果画面で確認してからマップへ戻る
- カードを削除・弱化しても、他のカードのID・効果・特殊ブロック・デッキ内の順序は変えない
- 永続的な基礎攻撃力低下はそのカードに保持し、戦闘やステージの終了でも維持する。複製した場合も引き継ぐ
- カードそのものを置換した場合（Enhanced化・ランダム変換）は変換先の定義を採用し、元の攻撃力低下は引き継がない
- デッキが7枚未満でも初期デッキに戻さず、その枚数のまま戦闘へ進む

## 癒やしの泉

- ID：`healing_spring`、出現ステージ：1・2・3
- 「水を飲む」：最大HPの25%を切り捨て、最低1HP回復。最大HPを超えない
- Gold消費なし。満タン時も選択でき、結果に実際の回復量（0を含む）を示す

## 忘却の書庫

- ID：`forgotten_library`、出現ステージ：1・2・3
- デッキの任意のカード1枚を選択して削除する。無料
- 確定前に対象と削除後の枚数を表示する
- 最後の1枚は削除できない。枚数が1以下なら理由を表示し確定不可

## 錆びた鍛冶場

- ID：`rusty_forge`、出現ステージ：1・2
- 基礎攻撃力2以上のカード1枚を選び、基礎攻撃力を永続で2下げて80G獲得する
- 基礎攻撃力は0まで低下できる。特殊ブロックの効果・コスト・レアリティは維持する
- 同じ種類の他のカードは変化しない。確定前に攻撃力の前後と80G獲得を表示する
- 対象がなければ理由を表示して確定不可

## 血の契約

- ID：`blood_pact`、出現ステージ：2・3
- 最大HPを永続で5減らし、最大MPを永続で1増やす
- 現在HPは新しい最大HPを超えた分だけ切り詰める。現在MPも1回復する（新しい最大MPまで）
- 最大HP6以上の場合のみ契約可能。条件を満たさない場合は理由を表示する
- 確定前に変更前後の最大HPと最大MPを表示する。Gold消費なし

## 気まぐれな井戸

- ID：`whimsical_well`、出現ステージ：1・2・3
- 20G以上で「20Gを投げ入れる」が選択可能。必ず先に20G消費し、以下のいずれか1つが起こる
  - 50%：80G獲得（支払いと合わせて差引+60G）
  - 30%：HP15回復（最大HPまで）
  - 20%：HP8喪失（最低0）
- 確率・支払い・HP0でゲームオーバーになる旨を選択前に表示する。現在HP8以下では死亡する可能性を強調する
- HP0の場合もまず結果を表示し、「ゲームオーバーへ」で敗北画面に進む。マップへ戻ったり再挑戦したりできない

## 不安定な錬成陣

- ID：`unstable_circle`、出現ステージ：2・3
- デッキ内の基礎ミノ（I・O・T・S・Z・J・L）を1種類選択する。同じ種類の全カードが対象
- Gold消費なし。以下のいずれか1つが起こる
  - 60%：対象全カードを対応するEnhancedへ置換
  - 25%：変化なし
  - 15%：対象全カードの基礎攻撃力をそれぞれ永続で1低下（最低0）
- 確定前に各確率、対象枚数、成功時の変換先を示す。対象がなければ理由を表示して確定不可
- 置換時もカードID・枚数・順序を維持し、他の種類には影響しない
