# イベント：基本仕様

## 基本

- イベントではステージに応じたランダムイベントが抽選で発生する
- すべてのイベントは「出現ステージ数」を持つ。出現ステージ数以外のステージではイベントが発生しない
- イベントはプレイヤーに選択肢を提示するものと、選択肢はなくユーザに固定の効果をもたらすものとがある
- 各イベントにおけるプレイヤーやゲーム全体におよぼす効果は、各イベントの詳細定義に記載する
- すべてのステージのイベントマス到達時に共通して「ショップ」のイベントが発生することがある
- ショップイベントは10%の確率で発生し、ショップマスに到達した際と同等の処理が行われる


## 怪しげな魔術（実装済み）

- [詳細仕様](./5_SuspiciousMagic.md)
- 出現ステージ：1・2・3。イベントマスでショップ抽選（10%）に外れた後、他の対象イベントと等確率で抽選する
- Gold消費なしで、選んだ基礎ミノ1種類をデッキ内ですべて対応するEnhancedに変える。0Gでも利用可能

## 変化の霧の支払い

- 「飛び込む」は所持Gold全額を失い、全基礎ミノを対応するEnhancedへ変換する。Goldが1以上かつ基礎ミノがある場合のみ利用可能
- 「何かを投げ込む」「無視する」はGoldを消費しない
- [詳細仕様](./4_MysteryChange.md)

## 追加イベント（実装済み）

[追加6イベントの詳細仕様](./6_AdditionalEvents.md)

| イベント | 出現ステージ | 主な効果 |
| --- | --- | --- |
| 癒やしの泉 | 1・2・3 | 最大HPの25%回復 |
| 忘却の書庫 | 1・2・3 | 選んだカード1枚を削除 |
| 錆びた鍛冶場 | 1・2 | カード1枚の基礎攻撃力−2、80G獲得 |
| 血の契約 | 2・3 | 最大HP−5、最大MP＋1 |
| 気まぐれな井戸 | 1・2・3 | 20Gを払い、50%で80G、30%でHP15回復、20%でHP8喪失 |
| 不安定な錬成陣 | 2・3 | 基礎ミノ1種類が60%でEnhanced化、25%で変化なし、15%で基礎攻撃力−1 |

- ショップ抽選（10%）に外れた後、出現ステージを満たす既存・追加イベントから等確率で1件抽選する
- 追加6イベントは実行後に結果を表示し、「マップへ戻る」で終了する。結果表示中の再実行は不可
- 井戸でHPが0になった場合は結果確認後にゲームオーバーへ進む
