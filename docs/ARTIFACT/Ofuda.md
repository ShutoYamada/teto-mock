# お札

- 実装状態：実装済み
- レアリティ：アンコモン（暫定）
- 販売価格：200G（アンコモンの標準価格）
- エリートドロップフラグ：false
- 店売りフラグ：true
- イベント抽選フラグ：false
- 入手はショップ限定。所持済みの場合は販売抽選の対象外。

## 効果

- プレイヤーターン中、手札の呪いカードをクリックすると1MPを消費して使用し、捨て札へ送る（消費MPと使用後の処理は暫定）。
- ミノの選択や盤面への配置は不要。攻撃・ブロック配置・呪いの不利益効果は発生しない。
- 手札から離れるため、そのターン終了時の呪い発動を回避できる。すでに発生した効果・盤面状態は解除しない。
- デッキからの永久削除や戦闘中の除外は行わない。リシャッフルして再び引いた場合は、再度使用できる。
- 所持していない場合、MPが1未満の場合、敵ターン中や戦闘外では使用できない。
- 手札では呪いカードにコスト「1」と「呪い・お札で使用」を表示する。通常のカード選択画面では引き続き通常の説明を表示する。
