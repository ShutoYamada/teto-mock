# 磁力ゴーレム

- 種類：ボス
- 出現ステージ：2
- HP：200
- 撃破時のゴールド：150G
- 実装状態：Webモックアップに実装済み。数値はバランス調整前の暫定値

出現・予告・判定の共通ルールは[ボス戦：共通仕様](./BOSS_SPEC.md)を参照。

## 攻略の狙い

横の構えでは行、縦の構えでは列を完成させる。次の構えに向けて盤面を準備する。

## 行動周期と固有能力

| 順番 | 行動 | 効果 |
| --- | --- | --- |
| 1 | 横の構え | 10ダメージ |
| 2 | 縦の構え | 10ダメージ |
| 3 | 磁力放出 | 16ダメージ |

- 行動1の予告中は、受ける行消去ダメージが2倍。列消去ダメージは等倍。
- 行動2の予告中は、受ける列消去ダメージが2倍。行消去ダメージは等倍。
- 行動3の予告中は、すべて等倍。
- 行と列を同時消去した場合は、行由来と列由来のダメージを分けて倍率を適用する。
- 配置ダメージは構えによらず等倍。盤面のブロックを移動させる能力はない。
