# ブロックイーター

- 種類：ボス
- 出現ステージ：1
- HP：125
- 撃破時のゴールド：100G
- 実装状態：Webモックアップに実装済み。数値はバランス調整前の暫定値

出現・予告・判定の共通ルールは[ボス戦：共通仕様](./BOSS_SPEC.md)を参照。

## 攻略の狙い

予告されたラインを食べられる前に完成させる。空いた場所を次の配置に使うこともできる。

## 行動周期と固有能力

| 順番 | 行動 | 効果 |
| --- | --- | --- |
| 1 | 通常攻撃 | 10ダメージ |
| 2 | 雄たけび | 自身に憤怒(3)を付与 |
| 3 | 丸かじり | 14ダメージを与え、予告した1行または1列のブロックをすべて削除 |

- 丸かじりの予告時、全行・全列から等確率で1本を選ぶ。空のラインも候補に含む。
- 削除はライン消去ではなく、ダメージ・コンボ・ブロックの消去時効果を発動しない。
- 従来のランダム行動とランダムな実行時削除を、固定周期と事前の対象予告に変更する。
