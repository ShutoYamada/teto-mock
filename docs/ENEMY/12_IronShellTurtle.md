# 鉄甲ガメ

- 種類：ボス
- 出現ステージ：1
- HP：140
- 撃破時のゴールド：100G
- 実装状態：Webモックアップに実装済み。数値はバランス調整前の暫定値

出現・予告・判定の共通ルールは[ボス戦：共通仕様](./BOSS_SPEC.md)を参照。

## 攻略の狙い

甲羅にこもっている間はライン消去を狙い、甲羅から出たターンは配置攻撃で攻める。

## 行動周期と固有能力

| 順番 | 行動 | 効果 |
| --- | --- | --- |
| 1 | 甲羅にこもる | 6ダメージ |
| 2 | 甲羅にこもる | 6ダメージ |
| 3 | 首を伸ばす | 12ダメージ |

- 行動1・2の予告中に限り甲羅状態となり、受けるカード配置時の基礎攻撃ダメージを50%にする。
- ライン消去ダメージ、コンボ追加ダメージ、カード特殊効果等は軽減しない。
- 行動3の予告中は甲羅状態を解除する。通常の防御状態とは別の固有能力として扱う。
