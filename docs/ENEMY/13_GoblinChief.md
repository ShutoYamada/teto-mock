# ゴブリン親分

- 種類：ボス
- 出現ステージ：1
- HP：110
- 撃破時のゴールド：100G
- 実装状態：Webモックアップに実装済み。数値はバランス調整前の暫定値

出現・予告・判定の共通ルールは[ボス戦：共通仕様](./BOSS_SPEC.md)を参照。

## 攻略の狙い

子分を減らして号令の被害を抑えるか、本体を先に倒すかを選ぶ。

## 行動周期と固有能力

| 順番 | 行動 | 効果 |
| --- | --- | --- |
| 1 | 子分を呼ぶ | 生存中の子分が2体になるまで補充する |
| 2 | 号令 | 本体が6ダメージ。生存中の子分それぞれに憤怒(2)を付与 |
| 3 | 親分の一撃 | 12ダメージ |

- 開始時は本体と子分1体。子分はボス専用ユニット「ゴブリンの子分」で、HP18、基礎攻撃3、撃破報酬0G。通常敵のゴブリンとは別定義。
- 子分は毎敵ターン1回攻撃する。本体、子分の出現順に行動し、号令は同じ敵ターンの子分の攻撃から適用する。
- 新しく召喚された子分は、その敵ターンは行動せず、次の敵ターンから攻撃する。召喚直後でも号令による強化対象にはなる。
- 子分は最大2体。補充された個体は憤怒を引き継がない。子分の追加召喚能力はない。
- 本体と子分の間に挑発やかばう効果はなく、攻撃対象は自由に選べる。
