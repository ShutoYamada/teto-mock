# 古代炉心

- 種類：ボス
- 出現ステージ：3
- HP：280
- 撃破時のゴールド：200G
- 実装状態：Webモックアップに実装済み。数値はバランス調整前の暫定値

出現・予告・判定の共通ルールは[ボス戦：共通仕様](./BOSS_SPEC.md)を参照。

## 攻略の狙い

大技の準備期間にライン消去を集中し、不発と転倒を狙う。

## 行動周期と固有能力

| 順番 | 行動 | 効果 |
| --- | --- | --- |
| 1 | 放熱 | 12ダメージ |
| 2 | 充填 | ダメージなし |
| 3 | 臨界放出 | 基礎36ダメージから、充填中の消去ライン数×8を減算。最低0 |

- 行動2の予告が始まる時点から行動3の実行直前まで、2プレイヤーターン分の消去ライン数を数える。
- 予告に累計ライン数、停止までの残り数、現在の臨界放出ダメージを表示する。
- 累計4ラインで準備を中断し、臨界放出を不発にする。さらに、その時点から次のプレイヤーターン終了まで自身を転倒状態にする。転倒の倍率は1.5倍で、既存の転倒とは重複せず長い方の期限を採用する。
- 中断後も行動周期は進み、行動3は何もしない。次周期の行動2予告時にカウンターを0へ戻す。
- 行動1予告中のライン消去はカウントしない。
