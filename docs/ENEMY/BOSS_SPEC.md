# ボス戦：共通仕様

本書と各ボスの個別仕様はWebモックアップに実装済みです。HP・ダメージ・ゴールド・必要ライン数はバランス調整前の暫定値です。

## 出現と進行

- ゲーム全体は3ステージ。ステージは各ルートマップの区切りを指し、マップ内の深さとは区別する。
- ステージ開始時に、そのステージの候補3種類から等確率で1種類を抽選し、最終ノードのボスとして固定する。ルート選択や画面の再表示では再抽選しない。
- ステージ開始時からボスの名前と固有能力を公開し、道中のデッキ構築に利用できる。
- ボス戦はボス本体をすべて倒すと勝利する。召喚された子分だけが残っていても戦闘を終了し、子分を消去する。双頭竜は両方の頭がボス本体に該当する。
- 報酬は戦闘勝利時に1回だけ付与する。召喚子分からゴールドは得られない。双頭竜の報酬は2体分を合計する。

## 行動と予告

- ボスは個別仕様に記載した固定周期で行動する。行動表の1行が1回の敵ターンに対応し、最終行の次は先頭に戻る。確率による行動抽選は行わない。
- 戦闘開始時に最初の行動を予告する。以降は敵ターン終了後、次のプレイヤーターンが始まる前に予告を更新する。
- ダメージ、攻撃回数、状態変化、対象の行・列、期限と解除条件を表示する。予告時に選んだ対象を実行時に再抽選しない。
- 次のプレイヤーターンに有効な構えや刻印は、そのターンの開始前に設定する。配置操作の途中では切り替わらない。
- 攻撃値は基礎値。憤怒などの既存効果を適用した最終値を予告する。連続攻撃には各打撃に補正を適用する。
- 一時効果の「1プレイヤーターン」は、付与後に始まるプレイヤーターンの開始から終了までを指す。
- 通常のライン消去で同時に行と列を消した場合は、それぞれ1ラインとして数える。同一ラインを作り直して再び消せば再加算する。敵能力による削除、爆発等による部分破壊はライン消去数に含めない。
- 固有効果の倍率は指定されたダメージ源だけに適用し、最後に小数点以下を切り捨てる。コンボ追加ダメージ、状態異常、アーティファクト等の独立した追加ダメージには適用しない。
- プレイヤーの攻撃と派生効果を解決して勝利判定を行い、勝利済みなら敵行動や期限切れ効果は発生しない。
- 盤面の座標は固定で、ブロックを削除しても他のブロックを詰めない。対象が空なら空のままとする。固有効果は戦闘終了時にすべて解除する。

## 実装と確認

- 各ステージ15層（深さ0〜14）のマップを生成し、3ステージ進行・ステージ別ボス抽選・開始時のボス公開を実装。ステージ間はHP・デッキ・ゴールド・アーティファクトを引き継ぎ、現在地をリセットする。
- ブロックイーターとヴァルキリーを固定周期へ変更し、ヴァルキリーはステージ2へ移動。
- 新規7種類のボス、召喚子分、盤面マーカー、固有カウンター、報酬と戦闘終了時の解除処理を実装。
- 自動テストは `pnpm test`、型チェックは `pnpm typecheck`。長時間の通しプレイによる難易度調整は今後行う。
