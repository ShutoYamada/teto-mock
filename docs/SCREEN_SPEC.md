# 画面仕様

テトリス+ローグライクゲームの各画面に関するUI/UX仕様です。

## 画面一覧

| 画面名             | 説明                                                 |
| ------------------ | ---------------------------------------------------- |
| ダンジョン画面     | ステージのルートマップを表示し、次の進行先を選択する |
| 戦闘画面           | テトリスフィールドでカードを配置して敵と戦う         |
| リザルト画面       | 戦闘勝利後の報酬選択画面                             |
| ゲームオーバー画面 | 敗北時に表示される画面                               |

---

## ダンジョン画面

### レイアウト

- **道・暗域**: ノード間を曲線の道で接続し、現在地から進める道とノードを強調する。暗域の未判明ノードは種類の代わりに「🌑 暗域」と表示する。ランタン所持時は全種類を表示し、案内文で効果を示す
- **配置・スクロール**: 深さごとのノード数と位置を変え、各ノードに歩数を添える。マップ表示時は現在地付近へスクロールする。狭い画面ではマップを横スクロール可能にする
- **現在地・マップ表示**: 画面中央部分に全体の分岐ルートマップを描画する
- **ノード（マス）**: クリック可能な円や四角で表示され、ボス（最深部）に向かって枝分かれ・合流するツリー状のUI
- **ボス情報**: ステージ開始時から最終ノードにボス名と固有能力の要約を表示する。ノードを確認すると詳細説明を読める
- **プレイヤーステータス**: 現在のHPや所持するリソース（ゴールド等）

### インタラクション

- 現在地から直接繋がっているノードのみがクリック・選択可能
- ノードを選択すると、指定されたイベント（戦闘など）画面へ遷移する
- ステージ開始時、スタート地点が1〜3つ表示され、プレイヤーが選択する

## 戦闘画面

### レイアウト構成要素

| 要素                     | 説明                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------- |
| テトリスフィールド       | 7×7（デフォルト）の盤面。カードを配置するエリア                                         |
| デッキ情報表示           | 現在の「山札(Deck)」と「捨て札(Discard)」の枚数を表示                                   |
| 手札エリア               | 現在の手札を表示する                                                                    |
| プレイヤーステータス表示 | HP・MPを表示する                                                                        |
| 敵情報表示               | 敵の数だけHP・次ターンの予告ダメージを表示する。<br/>現在のターゲットを視覚的に強調する |
| ターン終了ボタン         | クリックで敵ターンに移行する                                                            |

### インタラクション

- 手札からカードを選択してテトリスフィールド上に配置する
- カード選択中、特定の操作（右クリック、または指定のキー等）でカードの形状を回転できる
- 複数敵がいる場合、敵のステータス領域をクリックして攻撃対象(ターゲット)を切り替える
- 配置時にカード基礎攻撃力ダメージが即時発生する
- ラインが揃った場合、行・列の消去とダメージが発生する
- 連続消去時はコンボ表示と追加ダメージが発生する
- ターン終了ボタンを押すと敵の攻撃フェーズへ移行する

## リザルト画面

- 戦闘勝利後に表示される
- 獲得Gold量を表示する
- ランダムに選ばれたカード3枚を提示し、プレイヤーは1枚を選んでデッキに加える

## ゲームオーバー画面

- 戦闘敗北後に表示される
- 「最初からやり直す」などのアクションを提示する

## ボス戦の表示・操作

以下は[ボス戦仕様](./ENEMY/BOSS_SPEC.md)に対応する実装済みの追加UI。

- 敵情報に行動名、確定したダメージと攻撃回数、付与する状態、次の大技を表示する。防御や固有能力を確認できる説明を付ける。
- 対象ライン・マスは予告時から盤面に枠と記号で表示し、色だけに依存しない。カード配置の可否表示と重なっても両方が判別できるようにする。
- ブロックイーター：丸かじりする行または列と、削除までの期限を表示。
- 鉄甲ガメ：甲羅の有効・無効と「配置攻撃50%、ライン消去は等倍」を表示。
- ゴブリン親分：本体・子分のHP、各行動、子分数（最大2）、召喚直後の行動待ちを表示。各個体をターゲットにできる。
- ヴァルキリー：ドロー減少と、大技の1打あたりの攻撃値・回数を表示。
- 磁力ゴーレム：現在の構え、ダメージが2倍になる方向、次の構えを表示。
- 胞子の庭主：散布予定マスと生成済み胞子を区別し、各胞子に成熟までの残りプレイヤーターン数を表示。
- 古代炉心：充填中の消去ライン数、停止条件（4ライン）、残りターン、現時点の大技ダメージ、不発・転倒状態を表示。
- 双頭竜：2体のHP・行動予告・防御を個別表示し、撃破後の強化内容を事前に確認できる。片方の撃破時に残る頭の行動予告を更新する。
- 迷宮の設計者：刻印された行と列、解除状況、残りターン、更新後の裁定ダメージを表示。
- ライン消去や撃破で敵行動が変化したら、次の操作前に予告を更新する。
- 盤面は画面幅に合わせて縮小し、8×8でも全列を表示する。手札は盤面の下に配置し、縦に収まらない場合はページをスクロールする。手札が盤面の予告や配置操作を覆わないようにする。
