# ゲーム性仕様

テトリス+ローグライクゲームのゲームシステムに関する仕様です。

## 全体構成

- ダンジョン画面と戦闘画面から成る
- ダンジョンは3ステージ構成
- 1ステージごとにスタート地点からツリー状に分岐する。どの分岐ルートを選んでも最後はステージのボスにたどり着く
- 各ステージのボスは候補3種類からステージ開始時に等確率で抽選し、名前と固有能力を公開する。抽選結果はそのステージ中固定する
- ボス候補と共通ルールは[ボス戦仕様](./ENEMY/BOSS_SPEC.md)を参照する
- ボスを倒すと次のステージに進む
- 3ステージ目のボスを倒すとゲームクリア
- ボスに負けるとゲームオーバー

---

## ダンジョン

- 各ステージごとに1〜3のスタート地点があり、プレイヤーは任意のスタート地点を選ぶ
- 各ステージはボスを含む15ステップ。接続は必ず次の深さに進み、どの経路でもボスまでのステップ数は等しい
- 開始地点は1〜3個、途中の各深さは2〜4個のノードを生成し、配置を左右・上下にずらす。すべてのノードは到達可能で、行き止まりはない
- 途中の種類は戦闘45%、イベント17%、エリート14%、休憩12%、ショップ12%で抽選する。開始地点は戦闘、ボス直前は休憩に固定する
- スタート地点から分岐・合流する
- ステージ生成時に60%の確率で暗域を設ける。深さ3〜8のいずれかから連続3段を暗域とし、ボスは含めない
- 暗域はノードの位置と道を表示し、種類のみ隠す。現在地から直接進める位置に近づくと種類が判明し、一度判明した内容はステージ中保持する
- ランタンを所持している間はすべての暗域の種類が見える
- 各分岐ごとに「戦闘イベント」や「ランダムイベント」が発生する
  - 「戦闘イベント」: 敵と戦闘する
  - 「ランダムイベント」: アーティファクトを獲得する
